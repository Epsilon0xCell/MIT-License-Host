A note from the clerk

This page exists for one errand: it keeps one canonical copy of the MIT licence in one known place, so the text can be pointed at, fetched, and reused without hunting through old projects. The sheet above is the whole of what the repo holds, shown exactly as the file in the repo reads.

It is not legal advice, not a licence chooser, and not a generator with options. The repo ships one fixed text and no code at all, and this seal offers that text three ways: read it here, copy it, or take the file away.
