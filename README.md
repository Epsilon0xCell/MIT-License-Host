This repository hosts the MIT license. That is its whole contents: the
LICENSE file in this repo, plus this README and the branding images.
There is no code here.

> Clerk's slip: this repo contains no program to run. What it holds is the licence text, and the desk that hands it over.

The LICENSE file is the standard MIT license text, with the copyright
line in the form used in that file: Copyright (c) 2023 Gavin Blacklock (Gavin K.)
(@Epsilon0xCell). To use it, copy the LICENSE file into a project and
keep its copyright and permission notices intact, as the license text
itself requires.
